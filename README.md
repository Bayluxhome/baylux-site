# Baylux — сайт недвижимости (MVP)

Современный портал недвижимости для Батуми на **Next.js 14**. Дизайн в фирстиле Baylux
(Navy / Gold / Cream), карта объектов, страницы ЖК с вложенными квартирами, SEO-структура.

Данные пока хранятся локально в `src/data/data.js` (без внешних аккаунтов). Следующим шагом
подключается CMS (Sanity), чтобы заводить объекты через админку.

## Что внутри

- `/` — главная: герой, выбор города (Грузия → города), карта домов, свежие объекты, услуги.
- `/catalog` — каталог с фильтрами (сделка, тип, район) + карта.
- `/building/[slug]` — страница дома/ЖК: **внутри список всех квартир**, что продаются и сдаются.
- `/property/[slug]` — карточка конкретной квартиры с галереей, картой и заявкой.
- `sitemap.xml` и `robots.txt` генерируются автоматически (для Google).

## Как запустить локально (если есть Node.js 18+)

```bash
npm install
npm run dev
```
Открыть http://localhost:3000

## Как опубликовать в интернете (без Node на компьютере)

1. Создай бесплатный аккаунт на **github.com** и на **vercel.com** (войти через GitHub).
2. Залей эту папку `baylux-site` в новый репозиторий на GitHub
   (кнопка *Add file → Upload files*, перетащи всё содержимое папки).
3. В Vercel: **Add New → Project → Import** свой репозиторий → **Deploy**.
   Vercel сам определит Next.js, соберёт и выдаст ссылку вида `baylux-site.vercel.app`.
4. Когда купишь домен (рекомендация — один `bayluxhome.com`, см. документ
   «Домен и SEO-стратегия»): в Vercel → **Settings → Domains** добавь домен и
   пропиши DNS по инструкции Vercel. Перенос — пара кликов, код менять не нужно.
